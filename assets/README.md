# Подложка кадра

Кадры снимаются **поверх настоящего окна Telegram Desktop**: сюда кладётся
снимок окна, из которого руками удалён весь текст, кроме подписи «бот» под
заголовком.

| файл | что это |
|---|---|
| `tg-bg.png` | снимок окна 1920×1054 (ваш, личный — в git не попадает) |
| `placeholder.png` | заглушка для CI: однотонный тёмный фон, чтобы тесты рендера не падали без файла |

Требования к снимку:

- тёмная тема Telegram, портрет не нужен — размер произвольный, кадр 1:1;
- **без** пузырей, текста сообщений и поля ввода: их рисует ферма;
- подпись «бот» под заголовком — можно оставить, она часть интерфейса;
- имя файла начинается с `tg-bg.` — так рендер его находит.

Если файла нет, кейс всё равно прогонится: кадр просто не снится, а прогон
записывается в отчёт как `⚠️ кадр не снялся`. Это осознанно — отсутствие
подложки не должно выдавать сломанного бота.
